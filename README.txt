## Project Description
This project is a personal portfolio website developed using HTML5 and CSS3 as part of my HTML & CSS internship. It presents my introduction, educational background, technical skills, projects, and contact information. CSS Flexbox, Grid, and media queries are used to create a responsive layout for desktop and mobile screens. This project helped me practise webpage structure, styling, navigation, and responsive web design.
